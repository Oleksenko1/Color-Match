# Color Match

**Color Match** is a fun and fast-paced casual game where you control a color-changing basket to catch falling shapes. Match the basket's color with the shapes to score points and avoid the wrong ones! Perfect for quick, engaging gameplay on the go.

---

## Gameplay

- The basket changes its color every few seconds.
- Catch shapes that match the basket's current color to score points.
- Avoid catching shapes of the wrong color — or face the consequences!
- Two exciting modes:
  - **Time Mode** – Score as many points as possible before the timer runs out.
  - **Endless Mode** – Play as long as you can, but watch out — you only have a limited number of lives.
